# Statistics

## Status

Planned feature after **Edit In/Out Times**.

## Direction

This feature should provide useful aligner-wear statistics while preserving the application's minimal, performance-first design.

The detailed product specification has **not yet been finalized**.

Before implementation, define:

- which statistics belong in the first version
- date ranges
- tray-level vs day-level views
- whether charts are actually useful
- how statistics should be calculated efficiently from `WearPunch` and `TrayPeriod` history
- whether any cached/derived data is justified for performance

Do not let an implementation agent invent the full statistics product behavior without first updating this specification.
